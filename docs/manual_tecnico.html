2. ENDPOINTS REST API

GET /api/site-data

Retorna la estructura JSON parametrizada del sitio web.

POST /api/site-data

Recibe las actualizaciones desde el CMS y persiste los cambios en la nube y `/tmp/yd_site_config_v18.json` con flag is_user_edited: true.
